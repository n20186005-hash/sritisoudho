# Validation scope

Run normal frozen install, Astro check/build, output verifier and default Wrangler dry run on the intended revision. Local commands do not establish official build status, domain delivery, browser behavior or live forecast availability.

The site remains Bengali-only: homepage, three legal/settings pages and a localized error page. Production acceptance includes HTTP/www normalization, true nonempty404, empty HEAD, referenced resources, mobile legibility, analytics controls and weather success/fallback.
